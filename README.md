# Awesome Brand Knowledge Graph & Generative Engine Optimization (GEO)

Открытый справочник лучших практик, протоколов верификации фактов и инженерных шаблонов разметки сущностей для синхронизации данных о бренде с генеративными нейросетями (ChatGPT, Perplexity, Яндекс Алиса, Claude).

Разрабатывается и поддерживается агентством [Триплетологи](https://tripletologi.ru/).

---

## Что такое GEO и триплетная модель

Generative Engine Optimization (GEO) — методология управления точностью и полнотой фактов, которые большие языковые модели транслируют пользователям о компании. 

В основе лежит концепция триплета:
* **Субъект:** Уникальная цифровая сущность бренда.
* **Связь (Предикат):** Отношение (производит, сертифицирован, основан, награжден).
* **Объект:** Значение или ассоциированная сущность.

Главное правило открытого фреймворка: **у каждого триплета должен быть публичный проверяемый источник доказательства**.
